# Local font assets

Switzer 400, 500, 600 and 700: Indian Type Foundry / Fontshare.
Downloaded through Fontshare's official CSS API for local web embedding.
Source: https://www.fontshare.com/fonts/switzer
Terms: https://www.fontshare.com/terms

Cormorant Garamond italic: Google Fonts, SIL Open Font License. Locally instantiated at weight 400 and subset to Latin and punctuation for a smaller asset.
Source: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
The accompanying license is in Cormorant-LICENSE.txt.

Athelas is referenced only as an optional installed system font. No Athelas or Moara font binaries are included.
